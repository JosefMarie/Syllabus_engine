**Role:** Senior Full-Stack Software Engineer and UI/UX Architect.
**Objective:** Build a standalone, modern, interactive "Digital Syllabus Platform" for software development and design students. The platform replaces analog paper syllabi with a rich, mobile-first web application. It must allow teachers to author syllabi from scratch or automatically parse and structure existing syllabus files (PDF, Word, Text) using the Google Gemini API.

---

### 🛠️ Tech Stack:
- **Framework:** Next.js 15 (App Router, Server Actions, TypeScript)
- **Styling & Animations:** Tailwind CSS v4, Framer Motion, Lucide React (Icons)
- **Database & Storage:** Firebase (Firestore for JSON data, Firebase Storage for images/mockups)
- **Authentication:** Firebase Auth (Google Provider / Email restricted to Admin)
- **AI Engine:** `@google/genai` SDK using `gemini-2.5-pro` with Structured Outputs (JSON Schema)
- **Interactive Tools:** `@codesandbox/sandpack-react` (Code runner), `react-markdown` (Rich text rendering)

---

### 📂 Core Data Hierarchy:
The platform revolves around a strict 5-level nested structure:
`Syllabus Name` ➔ `Learning Outcome (LO)` ➔ `Indicative Content (IC)` ➔ `Topic` ➔ `Subtopic` ➔ `Content (Markdown + Code + Citations + Images)`

---

### 🗝️ Core Features & Architectural Requirements:

#### 1. Teacher Admin Portal (`/admin`):
- **Creation Hub:** A dashboard giving teachers two clear paths:
  1. **Build from Scratch:** An intuitive drag-and-drop / visual accordion editor to manually build the 5-level hierarchy tree.
  2. **AI Syllabus Extractor (Gemini Engine):**
     - Upload an existing syllabus file (PDF, DOCX, TXT).
     - Call a Next.js Server Action that sends raw text to `gemini-2.5-pro` using `responseSchema` to guarantee strict JSON formatting matching the 5-level hierarchy.
     - Auto-extract complex technical terms into a `citations` array (term, explanation, source) and code snippets into `codeSnippet`.
     - **Interactive Preview & Review Editor:** Before saving to Firestore, display an editable tree preview where the teacher can tweak, edit, add, or delete any extracted LO, IC, Topic, or Subtopic.
- **Publishing Workflow:** Draft vs. Published status toggles. Content stays invisible to students until set to "Published".

#### 2. Student Interactive Viewer (`/syllabus/[id]`):
- **Deep-Nested Navigation:** A left-hand sidebar (desktop) or slide-out drawer (mobile hamburger menu) representing the 5-level hierarchy with distinct level typography, icons, and indentations.
- **Contextual Citations Drawer:** Deep-dive explanations for key terms highlighted in text. Tapping a term opens a smooth Framer Motion **Side Drawer (Desktop)** or **Bottom Sheet (Mobile)**.
- **Executable Code Playground:** Embedded live coding environment using Sandpack so students can run/modify JavaScript and Node.js snippets directly in the browser.
- **Image Lightbox (Zoomable Images):** Click-to-zoom modal for high-resolution graphics, database ERDs, and Photoshop/Illustrator design mockups.
- **Reading Progress Tracking:** "Mark as Complete" checkmarks per Subtopic stored in LocalStorage / Firestore.

#### 3. Design System & UX Standards:
- **Aesthetic:** Clean, modern, "Stripe-Docs" / "Vercel-esque" documentation design.
- **Color Palette:** Deep Slate/Navy background tones, Emerald/Cyan accent highlights, clear contrast for code blocks.
- **Responsive Layout:** Mobile-first architecture engineered for seamless smartphone browsing.

## 🎨 Design System & Theme Configuration (Tailwind CSS v4)

### 1. Typography Pairings
- **Primary / Body Font:** `Inter` (Tall x-height, ultra-crisp legibility for deep nesting on smartphones).
- **Code & Structural Hierarchy Font:** `Fira Code` or `JetBrains Mono` (Ligature support for JavaScript and Node.js code blocks).

### 2. Color Palette Tokens
- **--color-slate-base**: `#0B0F19` (Deep Slate/Navy background)
- **--color-slate-surface**: `#1E293B` (Secondary containers, cards, sidebar)
- **--color-slate-border**: `#334155` (Subtle dividers and grid borders)
- **--color-brand-cyan**: `#06B6D4` (Active LOs, CTAs, highlight borders)
- **--color-brand-emerald**: `#10B981` (Code run status, completion checks)
- **--color-accent-citation**: `#F59E0B` (Dotted underline for deep-dive terms)
- **--color-text-main**: `#FFFFFF` (Headers, Titles, Code highlights)
- **--color-text-body**: `#CBD5E1` (Paragraph content, markdown text)
- **--color-text-muted**: `#94A3B8` (Metadata labels, level 4 subtopic indicators)

### 3. Global CSS Configuration (`globals.css`)
Configure Tailwind v4 using `@import` and the `@theme` directive:

```css
@import url('[https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;500;600&family=Inter:wght@400;500;600;700;800&display=swap](https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;500;600&family=Inter:wght@400;500;600;700;800&display=swap)');
@import "tailwindcss";

@theme {
  /* Typography Variables */
  --font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  --font-mono: 'Fira Code', 'JetBrains Mono', monospace;

  /* Color Palette Tokens */
  --color-slate-base: #0B0F19;      /* Deep Slate/Navy background */
  --color-slate-surface: #1E293B;   /* Secondary containers, cards, sidebar */
  --color-slate-border: #334155;    /* Subtle dividers and grid borders */
  --color-brand-cyan: #06B6D4;      /* Active LOs, CTAs, highlight borders */
  --color-brand-emerald: #10B981;   /* Code run status, completion checks */
  --color-accent-citation: #F59E0B; /* Dotted underline for deep-dive terms */

  /* Text Contrast Tokens */
  --color-text-main: #FFFFFF;       /* Headers, Titles, Code highlights */
  --color-text-body: #CBD5E1;       /* Paragraph content, markdown text */
  --color-text-muted: #94A3B8;      /* Metadata labels, level 4 subtopic indicators */
}

body {
  background-color: var(--color-slate-base);
  color: var(--color-text-body);
  font-family: var(--font-sans);
}

code, pre, .font-mono {
  font-family: var(--font-mono);
}

```
